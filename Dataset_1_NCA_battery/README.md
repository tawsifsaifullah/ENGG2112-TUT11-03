# Dataset_1_NCA_battery

This folder holds one example raw cell file from Dataset 1 (Zenodo record 6405084), used in Section 1 of the notebook.

The full dataset (66 files, about 580 MB) is too large for GitHub. To rebuild the feature table from the raw data, download Dataset_1_NCA_battery.zip from https://zenodo.org/records/6405084, unzip all CY*.csv files into this folder, and set REBUILD_FEATURES = True in the notebook.
